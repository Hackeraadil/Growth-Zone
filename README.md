# Boostly — Free Static Website

This is an original creator-services landing page inspired by the general structure of modern social-growth storefronts. It is NOT a copy of FameZone's source code, branding, assets, or proprietary design.

## Files
- index.html
- style.css
- script.js

## Run locally
Open `index.html` in a browser.

## Free deployment
Recommended: Cloudflare Pages.
1. Create a GitHub repository.
2. Upload these three files.
3. In Cloudflare Pages, connect the repository.
4. For a plain static site, leave build command empty.
5. Set output directory to `/` (or the repository root).
6. Deploy.

## Before taking real orders
- Replace the demo brand, prices and service descriptions.
- Add your real Privacy Policy and Terms.
- Connect the form to a secure backend or a legitimate contact/checkout service.
- Never put payment secret keys in `script.js`.
- Do not make misleading claims such as calling artificial engagement "organic".
