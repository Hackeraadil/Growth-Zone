FAQ

Questions, answered.

Can I change the brand name and colors?

Yes. Change the brand text in index.html and the CSS variables at the top of style.css.

Can I add Razorpay or another payment gateway?

Yes, but real payments should be connected through the gateway's official integration and a secure server-side flow. Do not put secret API keys in this static frontend.

Can this be hosted for free?

Yes. This static version can be deployed on Cloudflare Pages. A custom domain and payment/backend services may have separate costs.
